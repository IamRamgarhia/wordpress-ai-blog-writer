# Plugin Naming Recommendation — Search & Discovery Strategy

**Date:** 2026-08-23
**Context:** Plugin is v0.31.0, not yet published to wordpress.org (verified: searching "blogcraft" in the plugin directory returns 0 results). **This makes right now the cheapest possible moment to rename — before the first directory listing, reviews, and installs exist.**

---

## How users actually find a plugin like this

1. **WordPress.org directory search** (the #1 discovery channel). Users type: "ai content writer", "ai writer", "blog writer", "autoblog", "gpt". The directory matches against the plugin **name, slug, description and tags** — not the brand story.
2. **Google** for "best AI content writer wordpress plugin", "AI blog writer plugin free", "wordpress autoblog". Early on, the wordpress.org listing page ranks; later your own site does. A *unique* brand word is required to own your own query — a generic name drowns.
3. **The winning pattern used by every leader** (verified in the directory): **unique brand word + keyword-rich descriptor**:
   - "Yoast SEO – Advanced SEO with real-time guidance and built-in AI"
   - "GetGenie – AI SEO Assistant & Content Writer with Keyword Research, AEO & GEO"
   - "AI Puffer – Chat. Create. Automate."

**No name alone ranks you for "ai content writer plugin" on day one.** The name's job is to be *ownable and memorable*; the descriptor and tags' job is to be *findable*. The recommendation below packages all three.

## Assessment of the current name: "Blogcraft"

- ✅ Zero conflicts in the wordpress.org directory (verified).
- ✅ Short, easy to say, "craft" fits the quality-pipeline positioning.
- ❌ **Google collision with the DIY/crafts niche** — "blog craft" queries return craft-blog content; bare-word SERP is mixed with unrelated BlogCraft-named sites. Hard to own the query.
- ❌ Carries no AI/writer/SEO signal in the word itself.
- Verdict: usable, but leaves search value on the table.

## Recommendation

### 1st choice: **RankCraft**

**Display name (wordpress.org):**
`RankCraft – AI Content Writer & Blog Writer`

**Why it wins:**
- **"Rank" is the word in the user's head.** The competitive research showed the #1 motivation for buying these tools is ranking on Google. The name states the outcome the plugin is engineered for (quality gates, Google-friendly writing rules).
- **Keeps the "craft" heritage** from Blogcraft — the smallest possible rebrand distance; existing internal vocabulary (blueprints, archetypes, scorecard) still reads naturally.
- **Ownable compound** — two strong dictionary words, easy to spell and say, no dominant product occupying "RankCraft" in this space (neighbors: Rank Math, RankIQ — different constructions).
- **Verified: 0 plugin conflicts on wordpress.org** for "rankcraft".
- Caveat: rankcraft.com is registered (parked since 2012 by a domain reseller — likely purchasable). Workable domains: `rankcraft.ai`, `getrankcraft.com`, `rankcraft.io`. Run a routine trademark screen before committing.

**Slug:** `rankcraft`
**Tags:** ai content generator, ai writer, ai blog writer, content writer, autoblog, blog automation, seo content, openai, claude, gemini, gpt, automatic content
**Tagline / one-liner:** *"AI blog writer that researches first, writes in your voice, and checks its own work before it ranks."*

### 2nd choice: **DraftCraft**
- Verified 0 conflicts on wordpress.org. "Draft" evokes writing; "craft" keeps heritage. Weaker than RankCraft because it carries no ranking/SEO signal.

### 3rd choice: **PostPilot**
- Verified 0 conflicts on wordpress.org; perfectly signals the autopilot differentiator. **Caution:** postpilot.com is an active US direct-mail marketing SaaS — trademark risk in an adjacent software class makes this legally noisier than the others.

### 4th choice: **BlogForge**
- Verified 0 conflicts on wordpress.org. **Caution:** "forge" carries a double meaning of *forgery* — the wrong connotation for a product whose selling point is verified, trustworthy AI content.

### 5th option: **Keep "Blogcraft"**
- Viable — clean in the directory today. Weakest long-term Google ownership of the set. If kept, still apply the full search package below.

## The search package (matters more than the brand word)

Whatever name is chosen, apply all of this:

1. **Display name with keywords**: `Brand – AI Content Writer & Blog Writer` (avoid "WordPress"/"Plugin" in the name — directory guideline).
2. **Slug = brand word** (directory search matches slugs).
3. **All 12 readme tags** used, covering the exact query vocabulary: ai content generator · ai writer · ai blog writer · content writer · autoblog · blog automation · seo content · openai · claude · gemini · gpt · automatic content.
4. **readme.txt first paragraph** should contain "AI content writer", "blog post generator", "free", "bring your own API key" in natural sentences — this text is what the directory and Google index.
5. **Own domain + landing page** under the brand word (`rankcraft.ai` etc.) targeting "free ai content writer wordpress plugin" — the .org page and your landing page can hold two of the top ten Google results.
6. **Decide once, before first publish.** The competitive research documented users' anger at mid-flight rebrands (AI Power → "AI Puffer" with collapsing installs; Bertha abandoning its plugin; BotWriter neutering its free tier). A rename after launch burns accumulated reviews, installs and backlinks.
