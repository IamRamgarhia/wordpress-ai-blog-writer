**Applies to:** the AI writer plugin (copy written for the recommended name **RankCraft**; if you stay with "Blogcraft", swap the brand word — every other line is identical). Section 6 covers the same playbook for Open Migration and DiceStack.

**The core mechanic, stated once:** nobody types your brand name on day one. On WordPress.org, the directory search matches your **name, slug, description text, and tags** — so those must contain the words users actually type ("ai content writer", "autoblog", "openai"). On Google, the .org page and your own site rank only after the directory gives you installs and reviews. The listing below is engineered so both channels have something to bite on.

## 4. WordPress.org directory mechanics (the checklist that compounds)

1. **Search matching:** name + slug + description + tags all feed the query — that's why the copy above is keyword-loaded where it counts.
2. **First 150 characters** of the description are the snippet shown in results — never waste them on a slogan without keywords.
3. **Resolve every support thread.** The directory displays your resolution %, and unresolved threads kill conversion. Treat 100% as the target from day one.
4. **Keep "Tested up to" current** every WordPress release — users filter by compatibility.
5. **Frequent small releases** beat rare big ones (freshness signals + changelog trust). Even a rules-pack bump (per the campaign plan) counts.
6. **Answer every early review** — the first 5–10 reviews set the trajectory; your 5-star replies also demonstrate the support quality buyers check.
7. **No upgrade nags anywhere** — your no-upsell stance is itself a conversion asset in this upsell-fatigued category (top Reddit complaint of 2025–26).

## 5. Google side (what ranks, in order of when it works)

**Week 1 — directory does the work.** The .org page ranks for "rankcraft" and long-tails from your readme automatically. Nothing to do but keep the listing current.

**Month 1–3 — own-site pages targeting high-intent long-tails** (competition is low because paid tools ignore these queries):
- "free AI content writer WordPress plugin" (homepage title/H1)
- "AI blog writer with your own API key (BYO)"
- "free alternative to [Jasper / Koala / Surfer / SEOWriting]" — one honest comparison page each, with a cost table (your $0 + cents vs their $9–249/mo); these convert extremely well
- "write WordPress posts with Ollama / local AI models"

**Launch distribution (this is the real day-one engine):**
- **r/WordPressPlugins launch post** — free-no-upsell launches were front-paged twice in 2026 (a free Yoast alternative in Aug, a free Metorik clone in Apr). Post the philosophy + what it does + ask for brutal feedback.
- r/Wordpress, r/opensource, r/selfhosted (the Ollama angle is gold there — "write posts with a local model, zero API cost").
- Answer actual "which AI writer plugin?" questions in wp.org forums, Facebook WP groups, and r/Wordpress — with genuine comparisons, linking the plugin page.
- A dev.to / HashNode build-story article ("I built a staged critique-revise-verify writing pipeline as a free plugin") — this niche's articles reliably hit the top of Hacker News/Dev.to WordPress tags.

## 6. Same playbook, other two plugins (quick versions)

**Open Migration** — name already contains the keywords ("Migration", "Transfer", "Backup"). First paragraph must lead with the differentiator users search for: *"Free unlimited WordPress migration and backup — export your entire site and restore it anywhere. No size limits, no paid version, no extensions to buy."* Tags: `migration, backup, clone, migrate, move wordpress… (verify against directory vocabulary)`. **DiceStack** — the challenge is that "all-in-one" searches are fragmented; users search for the *individual* jobs ("caching plugin", "security plugin", "image optimization"). The description must enumerate every job it replaces in plain keyword text (caching, security, SEO, backups, image optimization, lazy load, webp…) because the directory search matches description body — each enumerated module is a separate discovery surface. The philosophy line ("replaces $500/year of subscriptions") is the conversion hook.
